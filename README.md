# MacroX
This macro helps you to enhance your movement in any fast-paced shooting game, especially for SNIPER DUELS.<br>
It also contains an automatic checker that checks if ROBLOX is down, using requests.<br>
This was made for those whose keyboard is trash and doesn't accept multiple keys at once or >100% keyboard users.

# How To Use
- Z - Quickswitches
- F1 - Toggles macro
- F2 - Changes quickswitch mode (1-->2 or 2-->1)

# Installation
1. Install the required packages found in requirements.txt using pip
2. Get the latest MacroX main.py file
3. Run it.
- I highly recommend you to run the file on the Windows console, but you can run on wherever yuo want to.
